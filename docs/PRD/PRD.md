# Biboo · 产品方案（PRD）

> 来源：产品经理与 Claude 讨论后整理的《跟读助教 · 产品方案》（2026-11-03），产品名定为 Biboo。

## 一句话定位

老师备一次课，跟读作业自动生成；孩子跟读由 AI 先听、先纠、先加练，老师只听 AI 拿不准的。

核心判断：

- 跟读批改是核心：每节课、每个孩子都要听，工作量随学生人数线性增长，是老师最重的课后负担。
- 课件生成是辅助：老师做好的课件会反复使用，频次较低，通用 AI 做 PPT 工具也已很多。它的价值在于和作业同源生成，让备课和留作业变成一步。
- AI 的真正价值不在打分：评测接口只会打分；把分数变成孩子听得懂的反馈、针对性加练和班级教学建议，才需要大模型。

## 目标用户与痛点

付费和决策的是老师，孩子和家长是被老师带进来的使用者。

| 用户 | 角色 | 痛点 | 现在怎么做 |
| --- | --- | --- | --- |
| 个体私教、小机构英语老师（首发） | 付费、布置作业、复核 | 课后要逐个听孩子跟读并指出问题；现成课件不合自己的教学习惯，只能自己手做 | 微信群收语音，一条条听、一条条回 |
| 幼儿园大班至小学低年级孩子 | 跟读、加练 | 不知道自己哪里读得不对，反馈要等老师有空 | 读完发给老师，隔天才有回复 |
| 家长 | 协助操作、关心进度 | 自己不一定会读，没法在家纠错 | 转发老师的语音给孩子听 |
| 公立小学英语老师（备选） | 同上 | 同样的跟读批改负担，且是合规场景 | 学校采购的作业平台或微信群 |

待验证：老师每周在听跟读上花多少时间，需要访谈 3–5 位老师拿到真实数字。

## 产品方案：三端闭环

核心数据是课时教学目标：这节课要学的词汇、句型、音标。课件和跟读作业都从它生成，孩子的跟读结果又反过来变成下节课的教学重点。

老师备课（网页端）：
1. 填入教学目标，或上传自己以前的课件让 AI 学习风格
2. AI 生成课件大纲和课堂活动（按模板和老师习惯），可编辑
3. 同时生成配套跟读作业：单词、句子、对话，配示范音频
4. 确认后一键发布到班级

孩子跟读（微信小程序，家长协助）：
1. 听示范 → 跟读录音 → AI 评测
2. 孩子友好的反馈：鼓励为主，只指出最重要的一两个问题
3. 针对出错的音自动生成加练，重读后提交

老师复核（网页端，手机可看）：
1. 班级看板：完成率、每个孩子的状态、全班共性问题
2. "需要你听"列表：只放 AI 拿不准或孩子多次失败的录音，老师可语音点评
3. 下节课教学建议，可一键加入下一次备课
4. 老师纠正 AI 的判断时自动记录，用于调整判定阈值

## AI 分工

成熟接口负责听和说，大模型负责理解和生成，规则负责边界和路由。

| 环节 | 谁来做 | 说明 |
| --- | --- | --- |
| 示范音频 | 语音合成 | 可选语速和音色 |
| 跟读打分 | 口语评测接口 | 输出整句、逐词、逐音素的得分和置信度；儿童语音准确率低于成人，需要单独评测 |
| 判定与路由 | 规则 | 按得分和置信度分为三类：读得好 / 有明确问题 / 交给老师 |
| 孩子反馈文案 | 大模型 | 把音素错误翻译成孩子听得懂的提示，只挑最重要的一两个 |
| 针对性加练 | 大模型 | 按出错的音生成简单单词和句子，限定在该年龄段的词汇范围内 |
| 班级共性问题与教学建议 | 大模型 | 汇总全班错误，生成下节课的重点 |
| 课件大纲与课堂活动 | 大模型 + 模板 | 老师历史课件作为风格参考 |
| 作业内容生成 | 大模型 + 规则校验 | 从教学目标生成，校验词汇难度和句长，老师确认后才发布 |

## 关键设计决策与能力边界

1. 错判比漏判伤害更大：只在置信度高时指出错误，核心指标是错误提示的精确率。
2. 拿不准就交给老师：低置信度、环境噪音大、同一句失败 3 次以上的录音进入"需要你听"，不对孩子显示错误结论。
3. 一次只指出一两个问题，鼓励在前，纠错在后。
4. 加练有上限：每个问题最多练 2 轮，练不好就交给老师。
5. 老师有最终决定权：作业内容必须老师确认才发布；老师可以推翻 AI 的判断，推翻记录用于校准。
6. 不替代老师的教学判断：不给孩子打总分、不做班级排名。

不做的事：照搬教材原文、建立共享教材库、给孩子排名或公布成绩。

## MVP 范围（15 天）与评测

跟读闭环做完整，课件生成只做最小版本（输入教学目标，输出可编辑大纲 + 作业）。

评测指标：错误提示精确率（核心）、转交率、老师耗时前后对比、加练后同一问题是否改善。具体阈值待第一批数据出来后再定。录音必须取得监护人同意；拿不到时先用成人模仿录音做原型，并在评测结论中注明。

## 商业模式

C 端是老师，不是家长。起步：个体私教、小机构老师，小班免费试用，超过学生数后按月订阅；扩展：小机构按席位或学生数收费；增值：家长额外加练内容、阶段学习报告。老师是分发渠道，家长端点开老师发的链接即可使用。

## 风险与合规

| 风险 | 应对 |
| --- | --- |
| 版权 | 以老师自定的教学目标为生成依据；不建共享教材库；老师上传资料仅本人可见 |
| 未成年人语音数据 | 监护人明确同意；最小化存储，设定保存期限；用于校准前单独授权且可关闭 |
| 教培政策 | 不只依赖校外机构；公立学校老师作为合规备选；上线前确认最新政策 |
| 儿童语音准确率 | 高置信度才判错，拿不准转老师；用老师纠正数据校准阈值 |
| 大平台覆盖 | 聚焦小机构和私教，以"同源生成 + 老师介入"为差异化 |
