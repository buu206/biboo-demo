> 配套文档：`docs/PRD/PRD.md`、`docs/阶段文档/技术适配声明.md`、AI Agent 产品 Vibe Coding 通用技术栈手册。

## 一、阶段目标
- 交付范围（对应《技术适配声明》第 7 节 2-1 行）：教学目标 → 跟读作业（单词、句子、对话）+ 示范音频 + 课件文字大纲；老师可编辑、确认、发布；作业存档。
- 阶段产物：后端服务、临时验收页、mock 测试、冒烟脚本、重启检查钩子、产品 README、证据包。
- 验收标准：
  - 填一份教学目标，30 秒内拿到课件大纲和跟读作业；
  - 单词项与老师填写的词汇完全一致（不由模型编造）；
  - 句子每句不超过 6 个词、包含本课词汇或句型；对话 2–4 行；
  - 大纲 3–6 个环节，时长合计约等于课时长度；
  - 老师可改任意一项文字；发布后才生成示范音频，发布后不能再改；
  - 服务重启后作业、大纲、音频都还在；
  - 内容质量按 D2 在第一次真实冒烟时由产品经理给 5–10 份样例打分定标准。
- 明确不做：孩子跟读录音、口语评测、分流、反馈与加练（2-2）；老师复核、看板、共性问题、录音清理、家长提醒（2-3）；正式前端（阶段 3）；上传历史课件学风格、导出 PPT（D11 暂缓）。
- 本阶段打通的主链路片段：老师登录 → 建班 → 填教学目标 → AI 生成 → 老师编辑 → 发布（生成示范音频）→ 查看与试听。

## 二、技术适配摘要
- 引用《技术适配声明》：后端先行；临时验收界面；D4 模型选型；D5 登录；D8 发布须老师确认。
- 本阶段采用：Python 3.12、FastAPI、Pydantic、pytest、Git。
- 本阶段启用：SQLite + SQLAlchemy + Alembic（多实体）；本地文件目录存示范音频；审计记录表。
- 本阶段适配：按产品经理确认，本机示范语音验收默认选择 AIHubMix，腾讯云仍可通过配置启用。运行环境和数据边界见第十二节。
- 开发路径：后端先行。

## 三、技术栈与模型
- 大模型：DeepSeek `deepseek-flash`（关闭思考模式），兼容 OpenAI 的接口；模型名、base_url、超时、重试次数全部走配置。
- 语音合成：`TTS_PROVIDER=aihubmix` 使用 AIHubMix 的 OpenAI 兼容 `/v1/audio/speech` 接口，默认 `gpt-4o-mini-tts`、`coral`、MP3，语速 `0.8`。`TTS_PROVIDER=tencent` 使用腾讯云 TextToVoice。两种配置共用单次超时、重试和发布时限设置。[AIHubMix 模型与接口](https://aihubmix.com/model/gpt-4o-mini-tts)
- 不引入：SSE、任务队列、Chroma、对象存储、口语评测（2-2 才用）。

- `BIBOO_FAKE_MODELS=1` 时用替身模型，只用于 mock 测试、重启检查和没有 Key 时看进度；验收页会醒目显示"模拟数据，未接真实模型"。

## 六、数据、资产与状态
- 持久化：SQLite（`data/biboo.db`），Alembic 管理表结构；音频存 `data/audio/<老师ID>/`，数据库记录路径、大小、类型、归属。
- 表（每张业务表都带 `owner_id` 老师归属）：

| 表 | 主要字段 |
| --- | --- |
| teachers | id、name、invite_code_hash、created_at |
| sessions | token_hash、teacher_id、expires_at |
| classes | id、owner_id、name、created_at |
| lessons | id、owner_id、class_id、topic、age_band、duration_minutes、vocabulary、patterns、sound_focus、status、outline（JSON，schema_version=1）、quality_notes、created_at、updated_at |
| homework_items | id、owner_id、lesson_id、kind（word / sentence / dialogue）、position、text、translation、audio_asset_id |
| assets | id、owner_id、kind（tts）、path、mime、size、created_at |
| audit_log | id、owner_id、event、detail（模型名、耗时、token、结果；不含完整内容）、created_at |

- 状态机（lessons.status）：`draft` →（生成成功）`generated` →（老师点发布且音频全部生成）`published`。`generated` 时可再生成、可编辑；`published` 后只读。生成失败保持原状态；发布时任一音频失败则回滚，保持 `generated`。

## 七、API 设计（前缀 /api/v1，错误统一 `{"error":{"code","message"}}`）

| 方法 路径 | 说明 | 主要错误码 |
| --- | --- | --- |
| POST /auth/login | 邀请码换 HttpOnly Cookie 会话 | INVALID_INVITE_CODE |
| GET /auth/me、POST /auth/logout | 当前老师、退出 | UNAUTHORIZED |
| POST /classes、GET /classes | 建班、列出自己的班 | VALIDATION_ERROR |
| POST /lessons | 建教学目标（草稿）：主题、年龄段、时长、词汇 1–12 个、句型 0–5 个、发音重点 0–5 个 | VALIDATION_ERROR、NOT_FOUND |
| GET /lessons?class_id=、GET /lessons/{id} | 列表、详情（含大纲、作业项、质量提示） | NOT_FOUND |
| POST /lessons/{id}/generate | 同步生成大纲 + 句子 + 对话；单词项由词汇直接生成 | MODEL_UNAVAILABLE、MODEL_OUTPUT_INVALID、INVALID_STATE |
| PUT /lessons/{id}/content | 老师按版本号编辑大纲和作业项文字 | INVALID_STATE、VALIDATION_ERROR |
| POST /lessons/{id}/publish | 老师提交明确确认和版本号后发布，逐项合成示范音频 | TTS_UNAVAILABLE、INVALID_STATE |
| GET /assets/{id} | 试听示范音频（只能取自己的） | NOT_FOUND |
| GET /health | 健康检查 | - |

- 别人的数据一律返回 NOT_FOUND，不暴露是否存在。
- 生成是同步请求：默认单次模型超时 12 秒、失败最多重试 1 次；SDK 初始化失败（如没 Key）也返回 MODEL_UNAVAILABLE，不返回堆栈。

## 八、Prompt 设计
- `homework_v1.md`：角色是少儿英语教研老师；输入是主题、年龄段、时长、词汇、句型、发音重点；输出固定 JSON：`outline`（3–6 个环节，每个含 title、minutes、activity）、`sentences`（3 句，每句含 text、translation）、`dialogue`（2–4 行，每行含 speaker A/B、text、translation）。写正例和"禁止"反例（禁止 Markdown、禁止编号前缀、禁止超出 6 个词的句子）。
- 解析：后端确定性解析，兼容"JSON 外面包了代码块、前后有多余文字"等常见情况；Pydantic 强校验结构。结构不合格重试 1 次，仍失败返回 MODEL_OUTPUT_INVALID。
- 数量和内容约束（句子超过 6 个词、没用到本课词汇、时长合计偏差大）不触发重试，记为"质量提示"，交老师看、交产品经理打分。

## 九、验收界面
- 临时验收界面：`backend/static/index.html`，单个 HTML、原生 JS，阶段 3 废弃；不做手机适配，是否表第 4、7 项填 N/A。
- 功能上限：邀请码登录、建班、填教学目标、生成、查看和编辑、发布、试听；没 Key 时显示"模拟数据"横幅。

## 十、测试要求
- 第一层 mock 测试（不少于 5 条）：解析器兼容代码块和多余文字；结构错误先重试、再失败返回统一错误；没 Key 时返回 MODEL_UNAVAILABLE 而非堆栈；单词项等于老师词汇；超长句子记质量提示但不失败；未登录 401；老师 B 读不到老师 A 的作业；状态机（未生成不能发布、发布后不能编辑）；发布生成音频并可试听；语音合成失败时回滚状态；输入校验（词汇为空、超过 12 个）。
- 第二层真实冒烟（`scripts/smoke.py`）：用虚构教学目标经 DeepSeek 生成五份评分样例，从其中一份验证发布、所选语音服务和试听。记录模型、请求 ID、token、耗时、结构校验和重试次数，样例另存给产品经理打分。配置齐两项服务的凭证后再运行。
- 重启恢复：`scripts/restart-check.sh` 新建，按手册契约；写入走"建班"接口（不调模型），读回班级名。

## 十一、验收清单（产品经理照着点）
- [ ] 打开验收页，用邀请码登录，能看到自己的名字
- [ ] 建一个班，填一份教学目标（例：家庭成员；mother、father、brother、sister；This is my ___.；th）
- [ ] 点"生成"，30 秒内出现课件大纲和作业；单词正好是你填的那几个

## 十二、风险与待确认项
- 本轮在 Mac 上接手，Python 3.12 已能安装依赖。真实模型连接、30 秒生成目标与试听效果待用凭证核验。
- DeepSeek 官方已更换模型 ID，默认用 `deepseek-flash`。为给 30 秒目标留出重试时间，生成调用默认单次 12 秒、最多重试一次。[DeepSeek 更新日志](https://api-docs.deepseek.com/updates/)
- 腾讯云配置使用公开列表里的英文音色 WeJack（101050，男声）。AIHubMix 配置的默认音色和读音效果待验。[腾讯云基础音色列表](https://cloud.tencent.com/document/product/1073/92668)
- OpenAI 公告 `gpt-4o-mini-tts` 的上游服务计划于 2027-01-06 停止，AIHubMix 的下线时间待核实。上线前重新核对模型可用性，可通过 `AIHUBMIX_TTS_MODEL` 切换并重做试听验收。[OpenAI Speech API 文档](https://developers.openai.com/api/reference/python/resources/audio/subresources/speech/methods/create)
- AIHubMix 本轮仅用虚构且无个人信息的示范文本验收。真实儿童录音和含个人信息的作业内容适用 D7 的境内处理要求。上线前核实 AIHubMix 路由和数据驻留。阶段 2-2 的发音评测单独验收。[AIHubMix 隐私政策](https://aihubmix.com/legal/privacy)
- 发布限时默认 30 秒。本机 AIHubMix 验收设置为 60 秒，以容纳逐项合成和重试。生成课件与作业的验收目标仍为 30 秒。同一份作业中相同文字共用音频，生成、编辑、发布按作业互斥。编辑和发布以版本号确认，发布过程中失败则保留待发布状态。
- 真实冒烟生成五份用于评分的内容，从其中一份验证发布和逐项试听。模型费用按实际调用计入开发验收预算。
