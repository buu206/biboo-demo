## 3. 怎么接手（推荐做法）
1. 把整个工具包放到电脑上：从 GitHub 下载 idea-to-launch-kit（Code → Download ZIP），解压。
2. 把工具包里的 `projects/我的第一个产品/` 删掉，换成本文件夹：复制 `Biboo` 整个文件夹到工具包的 `projects/` 下，得到 `projects/Biboo/docs/...`。
3. 在工具包根目录执行 `git init`（若不是 Git 仓库），确认 `.gitignore` 生效。
4. 用编码 AI 工具（Claude Code、Codex 等）打开工具包文件夹，发这句话：

```text
请读取项目根目录的 AGENTS.md，按其中"启动流程"开始。继续做 Biboo，当前在阶段 2-1。
```

5. 接手的 AI 应该：
   - 运行 `bash kit.sh 状态 Biboo`，确认管家记录是"阶段2-1 / 做中"；不对就用 `bash kit.sh 回到 Biboo 阶段2-1` 校正。
   - 读 `docs/项目状态.md`、`docs/阶段文档/技术适配声明.md`、`docs/阶段文档/阶段2-1技术开发文档.md`，不要重新做阶段 0、1。
   - 读通用手册第二、三部分，按 2-1 技术开发文档写代码：`backend/`（FastAPI + SQLAlchemy + Alembic，Python 3.12 虚拟环境在 `backend/.venv`）、`backend/tests/`（不少于 5 条 mock 测试）、`backend/static/index.html`（临时验收页）、`scripts/restart-check.sh`、`scripts/smoke.py`、产品 `README.md`。
   - 技术适配声明里写的"云端工作区"环境说明，换到本机后需要在 2-1 文档第十二节注明环境已变更（台账 D12 更新为"在产品经理的 Mac 上开发"）。
