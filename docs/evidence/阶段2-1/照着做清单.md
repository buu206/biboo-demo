# 阶段 2-1 验收清单

1. 打开本机 [Biboo 验收页](http://127.0.0.1:8000)，输入老师邀请码。页面右上角显示老师名称。
2. 输入「周六英语班」，点「建班」。当前班级会选中新建的班。
3. 填主题「家庭成员」、年龄「7–9 岁」、课时 25 分钟、词汇 `mother, father, sister`、句型 `This is my ___` 和发音重点 `th`。点「新建草稿并生成」，看是否在 30 秒内出现课件大纲和跟读练习。单词项应与填写的词汇一致。
4. 改一处大纲或一句作业文字，点「保存修改」。刷新页面，检查改动仍在。
5. 点「确认发布并生成音频」，检查状态变为「已发布」，各练习项有播放按钮，内容进入只读。模拟模式播放测试提示音。
6. 按[真实样例评分](真实样例评分.md)给五份生成结果各维度打 1–3 分，标出不能接受的内容。打开[家庭成员示范音频](示范音频-家庭成员.mp3)，听单句读音、节奏和清晰度是否适合孩子跟读。

用 AIHubMix 试听时，请沿用上面的虚构练习文字。启动、创建邀请码和凭证设置见产品 README。
