## 原有功能

1. 打开本机验收页，登录老师账号。从「我的课程」打开已发布课程，点「体验孩子端」。
2. 选 `think` 等练习，点示范音频播放。用浏览器录音，或上传 16 kHz 单声道 16 位 PCM WAV。验收录音使用同意参与的成人。
3. 点「提交跟读」，核对「读得好」「再练一轮」「等老师听」三种结果。孩子可见的结果只显示文字反馈。
4. 出现「再练一轮」时勾选加练，读对应文本并提交。第二轮加练仍有问题时应进入「等老师听」。刷新页面，检查原题、两轮加练和反馈仍在。
5. 点「换一个测试学员」复查独立记录。真实验收时准备 5–10 段成人模仿 `think` 的录音，分别覆盖读对、th 读错和背景噪音。核对分流，并对反馈和加练各打 1–3 分，标出任何误纠。

模拟模式的音频结果用于核对界面和流程，录音质量及发音分流效果以真实样例为准。

## 儿童课堂 PPT（2026-11-06 Demo 改进）

1. 打开 http://127.0.0.1:18766/ ，点「开始备课」后点「上传材料」，在「提供材料」中选择一份含英文词汇的教学材料，PPT 风格选「儿童互动（6–10岁）」，点「生成儿童互动 PPT」。
2. 看到「已生成 N 页课件，可下载编辑」后点「下载 PPTX」。打开文件，检查大图、短句和本课目标词是否适合孩子。海洋样例集中练习 arms、claws、tentacles、shell。
3. 开启 PowerPoint、WPS 或 Keynote 的幻灯片放映。在猜谜页点击一个错误选项，进入「One more try!」；点「返回猜谜」，再点正确选项，进入「Yes! You got it!」。按正常下一页也可以揭晓。
4. 按备注带领动作猜词、同桌轮流说句子和绘画分享。正常结束页后不应播放隐藏的重试页。
5. 修改一个词或一句话，保存并重新打开，确认文字可编辑。切换网页风格为「文字整理」，应清除旧下载结果并恢复文字版导出，两个模式都可保留。

儿童版使用固定课堂活动模板和已生成插画，不在每次导出时调用 AI。重点词最多四个；上传材料原文保存在教师备注供核对。当前主题图库有限，没有对应图片时显示 Biboo 引导角色，教师需要结合材料或实物讲解。原课件图片、动画、版式不原样保留。


## 简化后的课程操作（2026-11-08）

发作业原流程已由产品经理验收通过。本轮核对新的交互是否更顺手：

1. 登录后先看到 Biboo 备课助手。点「开始备课」，再点「海洋探险」再点「帮我准备」，应整理出海洋动物主题、octopus/crab/turtle/fish、6–8 岁和 25 分钟。确认前课程数不增加，原始描述可查看。
2. 核对目标和班级后点「生成这堂课」，进入课程详情。也可以从首页「自己填写」直接进入确认目标页。只输入中文且没有英文目标词时，应提示补充，不替老师编造词汇。
3. 作业先显示预览。点「修改内容」改一句，直接「发布作业」，核对修改已保存、作业已发布；打开「体验孩子端」能读到同一句。
4. 进入「课堂课件」下载 PPT；回「课后作业」查看链接。点「返回首页」并刷新，课程仍在；跨班级筛选不会打开别的课。
5. 首页点「上传材料」，可以直接生成 PPT，不需要创建或发布作业。此入口与首页文字描述独立。整理失败应保留原描述并允许重试。
6. 课程中的「看反馈」打开对应课程；从反馈带入下节课时，班级和建议保留，原课程不变。
7. 手机宽度下，首页输入框、弹窗和主要操作按钮应完整可用，Esc 可关闭弹窗并返回原按钮。修改未保存或首页描述未提交时刷新应有提醒；自填描述点击示例时，取消替换应保留原文。

当前仍为本机 Demo，发布不自动发送家长消息，复制的链接须在这台电脑的同一演示账号中打开。

## Biboo 场景首屏（2026-11-08 按参考截图重做）

1. 打开 http://127.0.0.1:18766/?v=owl-4 。首页应是居中的黑色大标题、两枚圆形插画、两侧教学道具和底部原有紫色猫头鹰 Biboo；原先四个角色围绕输入框的布局已替换。
2. 鼠标在首屏左右移动，观察道具与云层不同幅度的位移；靠近一个道具，它会轻微让开并转动，离开后缓缓归位。向下滚动时，云层与前景有不同速度的位移。
3. 停在底部猫头鹰 Biboo 上，应挥翅并出现问候；点一下会跳起回应。点击「开始备课」，页面滚到下一屏「下一堂课，想讲什么？」并聚焦输入框，不会自动提交。
4. 输入备课想法，或选「海洋探险」后点「帮我准备」，确认目标后生成 Demo 课程；也可以点「上传材料」直接生成 PPT。发布仍由老师主动点击。
5. 点「先玩一堂示例课」，进入互动预览。翻到第二页，选 crab 和 octopus，分别显示再试与答对反馈；跟读示例可切换 turtle，反馈示例可筛选「等老师听」。示例不录音、不评分、不修改实际课程。
6. 预览下的「用我的材料做课件」「准备一份跟读作业」「打开我的课后反馈」仍接原有真实功能入口。切换预览应保留尚未提交的输入；Esc 关闭弹窗应返回原按钮。
7. 手机点按操作相同，页面不应横向滚动；系统开启「减少动态效果」后，漂浮、视差、挥手停止，按钮功能保留。背景在打开弹窗、离开首页或切到其他标签后暂停。

网页里的课堂玩法是交互示例，实际 PPT 仍通过现有儿童模板导出；本轮重绘网页插画不改动之前已验收的 PPT 模板。

## 加练更新复验

保留现有三条录音与老师复核记录，新提交才采用新版提示。明确单音问题应显示一个具体动作、允许的练习词和示范入口；多个低分应说明需老师帮助确定重点。不要为了进入加练反复刻意改读音。受控接口测试只用于核对文字与语音，真实单音样例、儿童适用性和阈值校准仍待后续样例验证。
